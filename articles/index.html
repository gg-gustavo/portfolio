Pipeline Fluxo de trabalho da coleta

  1. Busca no OpenAlex — aplicação dos filtros, exportação do arquivo .bib com 66 registros e salvamento dos dados brutos (JSON).
  2. Download automatizado — execução do script baixar_pdfs.py, que baixou 23 PDFs e registrou o log em download_log.csv.
  3. Coleta manual — recuperação ativa de 37 PDFs a partir dos links retornados pela API (quando o download automático falhou ou não cobriu).
  4. Consolidação — validação de integridade dos arquivos, verificação de duplicatas e organização final do corpus com 60 artigos.

Como reproduzir Reexecutando o pipeline de coleta

O download automatizado da 1ª Coleta é reproduzível a partir do script baixar_pdfs.py, executado na raiz da pasta de coleta:

python3 baixar_pdfs.py

Requer requests (pip install requests).
